# PokeApi
 Pokédex feita com **HTML, CSS e JavaScript puro**, que consome a [PokéAPI](https://pokeapi.co/) para buscar informações de qualquer Pokémon. O fundo da página muda de cor de acordo com o tipo do Pokémon.

🔗 **Demo:** https://joaovsena123.github.io/PokeApi/

## O que o projeto faz

- Busca um Pokémon pelo **nome ou número** (ex.: `pikachu` ou `25`).
- Mostra foto, nome, número, altura (em metros) e peso (em kg).
- Exibe os **tipos** em etiquetas coloridas (um Pokémon pode ter 1 ou 2 tipos).
- Mostra os 6 **atributos** (HP, ataque, defesa, ataque especial, defesa especial e velocidade) com barras de progresso.
- Muda o **fundo da página** conforme o tipo: cor sólida para um tipo e degradê para dois tipos.
- Valida o campo vazio e avisa quando o Pokémon não existe.
- Mostra a mensagem "Buscando pokemon..." enquanto espera a resposta da API.

## Tecnologias

- HTML5
- CSS3
- JavaScript 
- [PokéAPI](https://pokeapi.co/) (API pública, sem necessidade de chave)
